01 / THE PROBLEM

Network behavior is visible in the data—if the data is usable.

Network assurance teams work with telemetry, logs, and utilization histories that vary in format and quality. Analysis depends on getting those signals into a condition where a use case can be evaluated, then delivering useful model outputs where they can be consumed.

My work on a telecom network-assurance platform included SD-WAN utilization time series and OT network data such as SolarWinds data and Splunk syslogs. The client and exact operating context are intentionally not named here.

02 / MY CONTRIBUTION

Worked across the path from raw signal to service.

I contributed data cleaning and engineering for large datasets, statistical time-series analysis, use-case-specific generalized ML models, and backend microservices to deploy AI/ML solutions using FastAPI.

My roleData Engineer, Data Scientist, and Backend Developer across analysis and service delivery.
