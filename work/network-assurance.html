01 / THE PROBLEM

High-velocity telemetry is only useful if it can be acted upon.

Within Infosys Network Engineering Services on the Infosys Smart Network Assurance (ISNA) platform, telecommunications networks generate relentless torrents of operational telemetry: fluctuating SD-WAN bandwidth utilization, SolarWinds OT metrics, router interface status events, packet loss bursts, and Splunk syslogs across distributed edge nodes.

Network operations centers (NOCs) struggle with alarm fatigue—drowning in thousands of un-correlated static threshold alerts while root causes remain obscured. Turning this chaotic stream into proactive incident resolution required end-to-end client requirement and feasibility analysis, distributed data engineering (PySpark, Apache NiFi, Apache Kafka, Elastic Stack), and calibrated time-series ML models delivered through FastAPI and Kubernetes microservices.

STATIC THRESHOLD ALARMS

NOC alarm fatigue & reactive triage

Static utilization thresholds fired thousands of uncorrelated alerts during normal business-hour traffic peaks, masking genuine link degradation.

ISNA TIME-SERIES AIOPS

Seasonal decomposition & FastAPI K8s dispatch

PySpark, NiFi, and Kafka pipelines feed seasonal time-series anomaly detectors served via FastAPI and Argo CD GitOps before link failure occurs.

02 / MY CONTRIBUTION

Bridging the entire journey from raw signal to live service.

My contributions spanned data engineering, predictive modeling, and production backend deployment:

  • Data Engineering & Ingestion: Built high-throughput data cleaning pipelines to normalize large-scale SD-WAN utilization series, OT network metrics (SolarWinds), and unstructured Splunk logs.
  • Time-Series Analysis: Performed statistical decomposition (trend, seasonality, noise) and trained generalized ML anomaly detectors to isolate degradation patterns before catastrophic link failure.
  • FastAPI Microservices: Implemented asynchronous REST APIs to serve model predictions and anomaly scores with sub-second response times.
  • Automated Delivery Infrastructure: Configured Docker containers, Kubernetes deployments, and GitOps automation with Argo CD, Ansible, and Jenkins.

Decoupling the data pipeline from the operational runtime.

CONCEPTUAL SEQUENCE · CLIENT TOPOLOGY OMITTED
01 / SIGNALS

Start with operational data.

Continuous ingestion of SD-WAN interface utilization metrics, OT network telemetry, and Splunk syslogs across distributed edge nodes.

02 / PREPARE

Make heterogeneous inputs usable.

Timestamp alignment, missing packet imputation, deduplication, and schema homogenization across varied network telemetry standards.

03 / ANALYZE

Decompose behavior over time.

Rolling statistical windows identify cyclical utilization baselines, separating normal business peak traffic from anomalous saturation spikes.

04 / MODEL

Calibrate models to use-case risks.

Trained classifiers and forecasting models evaluate multi-variable risk metrics without assuming identical behavior across different branch topologies.

05 / DELIVER

Expose results through resilient APIs.

FastAPI endpoints stream anomaly probabilities directly to NOC dashboards and automated ticketing workflows with low latency.
