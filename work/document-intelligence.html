01 / THE PROBLEM

Crucial enterprise context hides inside visual page structure.

In large organizations, critical operational information rarely exists as clean, uniform plain text. Policies, architecture guides, and compliance disclosures are frequently buried in scanned PDFs, multi-column tables, visual flowcharts, and technical diagrams across disparate internal repositories.

Standard keyword searches and naive text-only vector retrieval fail because they strip away the spatial layout, miss text baked into raster graphics, and produce hallucinations when questions require synthesising facts across both textual and visual evidence.

02 / MY CONTRIBUTION

Connecting retrieval strategies with visual document understanding.

My work focused on engineering the retrieval, verification, and multimodal extraction pipeline:

  • Advanced RAG Methods: Implemented Corrective RAG (CRAG) and Graph RAG (GRAG) patterns to detect retrieval ambiguity and verify retrieved context before passing it to language models.
  • Self-Query & Text-to-Query: Built query-transformation layers that extract metadata filters (department, effective date, document type) directly from natural-language questions.
  • OCR & Image Processing: Integrated layout-aware optical character recognition and bounding-box extraction for charts, tables, and scanned document pages.
  • Internally Hosted OSS LLMs: Deployed and served open-weight models on secure internal infrastructure, ensuring data remained entirely within organizational boundaries.
Role Responsibility AI Engineer and Backend Developer on the enterprise document-intelligence core.

01 / INPUT

Start with mixed evidence.

Enterprise documents combine searchable text with scanned pages, tables, graphs, and flowcharts. Ingestion must treat visual layout as first-class context.

02 / EXTRACT

Bring visual content into view.

OCR algorithms and image bounding-box extractors convert scanned figures and tables into structured markdown tables and image tokens.

03 / RETRIEVE

Connect questions to precise context.

Hybrid retrieval fuses dense vector similarity with BM25 sparse matching, guided by CRAG verification to filter out noisy context chunks.

04 / ANALYZE

Internal open-source LLM inference.

High-capacity open-weight models run strictly on internal inference hardware, enforcing organizational data containment and zero egress.

05 / REVIEW

Deliver transparent, assessable answers.

Answers include snippet citations, confidence ratings, and bounding-box coordinates for instant human verification.

02

Layout-Aware Chunking

Documents are chunked by structural headings, tables, and visual sections rather than arbitrary character token windows.

03

CRAG evaluates retrieved passage relevance before inference, triggering automated query refinement if confidence falls below threshold.
